# 안녕하세요, 프론트엔드 개발자 선입니다. 👋

사용자가 직접 경험하는 서비스를 만드는 데 흥미를 느끼며,  
화면 구현을 넘어 서비스 구조와 데이터 흐름까지 함께 고민하는 개발자가 되고자 합니다.

React, Next.js 기반으로 프로젝트를 개발해 왔고,  
컴포넌트 설계, API 연동, 상태 관리, 유지보수성을 함께 고려하는 프론트엔드 개발에 관심이 많습니다.
